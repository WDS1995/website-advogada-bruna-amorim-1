## Como usar

1. Abra `index.html` no navegador.
2. Navegue pelas paginas pelo menu superior.
3. Ajuste textos, contatos e redes sociais conforme os dados oficiais.

## Customizacao rapida

- **Paleta e tipografia**: editar `assets/css/theme.css`.
- **Layout global e utilitarios**: editar `assets/css/style.css`.
- **Componentes especificos**: editar os arquivos em `assets/css/components/`.
- **Menu mobile**: `assets/js/menu.js`.
- **Animacoes scroll + validacao do formulario**: `assets/js/scroll.js`.

## Pontos para atualizar antes de producao
